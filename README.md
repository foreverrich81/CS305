# CS305
Software Security


  Artemis Financial is a financial services company that provides investment and financial planning solutions for its customers. The company wanted to improve the security of its software application because it handled sensitive financial data and needed to protect customer information from cyber threats. The primary issue was identifying and addressing vulnerabilities within the application. To solve this, a comprehensive security assessment was performed, including dependency checks and vulnerability analysis. The goal was to strengthen the application's security, ensure data integrity and confidentiality, and help Artemis Financial meet industry security standards and maintain customer trust.
